## 🔍 What I do

- **Manual web application testing** — OWASP Top 10, business logic, authentication and access control
- **API security testing** — OWASP API Security Top 10 (BOLA, broken auth, mass assignment)
- **Android application testing** — OWASP MASVS, static and dynamic analysis
- **Vulnerability validation** — confirming real, exploitable issues, not scanner noise
- **Remediation guidance** — clear, developer-focused fixes for every finding
